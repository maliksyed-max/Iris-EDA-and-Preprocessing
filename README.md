# Iris Dataset — EDA and Data Preprocessing

## 📌 About the Project

This project performs Exploratory Data Analysis (EDA) and data preprocessing on the Iris dataset using Python. The analysis explores the structure, distribution, relationships, and characteristics of different Iris flower species.

## 🎯 Objectives

- Understand the Iris dataset and its features.
- Perform data cleaning and preprocessing.
- Analyze feature distributions.
- Identify relationships between numerical features.
- Visualize patterns in the dataset.
- Prepare the dataset for further machine learning applications.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

## 📊 Dataset

The Iris dataset contains measurements of Iris flowers, including:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## 🔎 Methodology

1. Load the Iris dataset.
2. Inspect the dataset structure and statistics.
3. Check for missing values and data inconsistencies.
4. Perform data preprocessing.
5. Conduct exploratory data analysis.
6. Generate visualizations to understand feature relationships.
7. Analyze patterns among different Iris species.

## 📂 Project Files

- `Complete data preprocessing.py` — Data preprocessing operations.
- `EDA on Iris Dataset.py` — Exploratory analysis and visualizations.
- `Exploratory_data_analysis.py` — Additional EDA implementation.
- `iris.xlsx` — Iris dataset.
